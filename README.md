# BattleShip-Project
A Java-based Battleship game developed using object-oriented programming and multiple computer-controlled AI strategies.
Features:
 - Interactive Battleship gameplay
 - Object-oriented class structure
 - Multiple AI difficulty levels
 - Ship placement and hit detection
 - Advanced AI search strategy

AI Strategies
 - Simple AI: The Simple AI selects available cells using a randomized search strategy.
 - Advanced AI: The Advanced AI uses a search-and-target approach. After detecting a successful hit, it searches adjacent cells to identify the direction and location of the remaining ship.

Technologies
 - Java
 - Object-Oriented Programming
 - ArrayList
 - Inheritance
 - Data Structures & Algorithms
